# Task 1: Titanic Survival Prediction

## Objective

The objective of this project was to build a Machine Learning model capable of predicting whether a passenger survived the Titanic disaster.

The dataset contains passenger information such as age, gender, ticket class, fare, cabin, and survival status.

## Workflow

1. Imported the dataset.
2. Explored the structure and characteristics of the data.
3. Performed data cleaning and preprocessing.
4. Handled missing values.
5. Prepared relevant features.
6. Divided the dataset into training and testing sets.
7. Trained a classification model.
8. Generated predictions.
9. Evaluated the model performance.

## Machine Learning Type

Classification

# Task 3: Iris Flower Classification

## Objective

The objective of this project was to classify Iris flowers into their respective species using sepal and petal measurements.

The three species included in the dataset are:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

The internship task specifically focuses on using sepal and petal measurements to classify the flowers.

## Workflow

1. Loaded the Iris dataset.
2. Performed exploratory analysis.
3. Examined the flower measurements.
4. Prepared the input features and target variable.
5. Split the dataset into training and testing data.
6. Trained a classification model.
7. Generated predictions.
8. Evaluated the model.

## Machine Learning Type

Multi-class Classification

# Task 5: Credit Card Fraud Detection

## Objective

The objective of this project was to build a Machine Learning model capable of identifying fraudulent credit card transactions.

The task involved preprocessing and normalizing transaction data, handling class imbalance, training a classification model, and evaluating its performance using suitable metrics.

## Workflow

1. Loaded and explored the transaction dataset.
2. Performed data preprocessing.
3. Normalized the transaction data where required.
4. Analyzed the distribution of fraudulent and genuine transactions.
5. Addressed the class imbalance problem.
6. Split the dataset into training and testing sets.
7. Trained a classification model.
8. Generated predictions.
9. Evaluated the model.

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score

## Machine Learning Type

Binary Classification
